<h3>Traducción en español para <strong>Edain Mod All in One</strong></h3>

<p>🧡 <strong>Gracias por llegar hasta aquí</strong></p>

<p>
Este proyecto nace con la intención de facilitar a la comunidad hispanohablante
la traducción del <strong>Edain Mod</strong> para
<em>El Señor de los Anillos: El Resurgir del Rey Brujo</em>,
utilizando el entorno <strong>All-in-One</strong>.
</p>

<p>
El launcher detecta automáticamente tu instalación y aplica la traducción
de forma segura y sencilla.
</p>

<br>

<h3>✨ Características</h3>
<ul>
  <li>✅ Compatible con <strong>All-in-One.</strong></li>
  <li>🧠 Detección automática de idioma.</li>
  <li>📦 Aplicación directa del pack de traducción.</li>
  <li>💻 Aplicación portable (no instala nada en el sistema).</li>
</ul>

<br>

<h3>🚀 Cómo usar el launcher</h3>
<ol>
  <li>
    Accede a la sección <strong>Releases</strong> del repositorio:<br>
    👉 <a href="https://github.com/f3l3p1n0/EdainMod_Spanish/releases" target="_blank">
    https://github.com/f3l3p1n0/EdainMod_Spanish/releases</a>
  </li>
  <li>Descarga el archivo <code>EdainSpanishLauncher.exe</code></li>
  <li>Ejecuta el launcher (doble clic)</li>
  <li>
    Asegúrate de que:
    <ul>
      <li>RotWK está en <strong>inglés</strong></li>
      <li>Edain está <strong>instalado y activo</strong> en All-in-One</li>
    </ul>
  </li>
  <li>Pulsa <strong>“Aplicar traducción”</strong> y espera a que finalice</li>
</ol>

<br>

<h3>⚠️ Aviso de Windows SmartScreen</h3>

<p>
Es posible que al ejecutar el launcher Windows muestre el siguiente aviso:
</p>

<blockquote>
  <strong>Windows protegió tu PC</strong><br>
  Microsoft Defender SmartScreen impidió el inicio de una aplicación no reconocida.
</blockquote>

<p>
Esto es <strong>normal</strong> y ocurre porque el ejecutable no está firmado digitalmente.
</p>

<p>
Para continuar:
</p>

<ol>
  <li>Pulsa <strong>Más información</strong></li>
  <li>Después, <strong>Ejecutar de todas formas</strong></li>
</ol>

<p>
El launcher <strong>no contiene software malicioso</strong> y está compilado directamente
a partir de este proyecto. Con el tiempo, Windows dejará de mostrar este aviso.
</p>
